中国美术史虚拟展厅

项目简介

本项目是大一“中国美术史”课程的结课作业，使用 Unity 引擎将传统的线下展览转化为可在线交互的虚拟展厅。观众可通过浏览器直接访问，在三维空间中自由漫游，近距离欣赏以左翼美术运动为主题的经典作品海报。

技术实现

· 引擎：Unity
· 发布平台：WebGL
· 托管部署：GitHub Pages
· 展厅模型：使用网上公开的免费展馆模型资源，经调整适配后用于本项目
· 展览内容：围绕左翼美术运动，收集相关美术作品并制作成展览海报，布置于虚拟展厅中

操作说明

· 鼠标拖动：旋转视角
· W/A/S/D 或方向键：移动
· 手机端手指滑动旋转视角

关于本项目

这是我大学期间第一次尝试将美术专业知识与游戏引擎技术结合。从寻找合适的展馆模型、调整灯光与材质，到将左翼美术作品制作为展品海报并合理布置于空间之中，整个过程让我初步体会到了“用技术呈现内容”的乐趣。

这个项目也是我第一次将 Unity WebGL 项目部署到 GitHub Pages 上，实现了无需下载、打开浏览器即可访问的便捷体验。
